# Schema Guard

`src-tauri/src/db/schema.rs` への変更時に不可逆操作を検出・警告する。

**参照ドキュメント:** `ARCHITECTURE.md#DB 設計のポイント`（スキーマ構造・FTS5 設計の背景）

## トリガー条件

- `src-tauri/src/db/schema.rs` を編集しようとしている場面

## 動作手順

1. 変更内容から以下の危険操作を検出する:
   - 既存カラムの削除・型変更
   - NOT NULL 制約の追加（既存データへの影響）
   - テーブルの削除・リネーム
   - FTS5 仮想テーブルの構造変更
2. 危険操作を検出した場合:
   - 影響範囲を特定する（`src-tauri/src/db/repository/` 内の参照箇所を grep）
   - 段階的マイグレーション戦略を提案する（例: 新カラム追加 → データ移行 → 旧カラム削除）
3. FTS5 インデックス変更は再構築コストが高いことを明示して注意喚起する
4. 安全と判断した変更（新規テーブル追加・nullable カラム追加等）は問題なしと報告する

## 制約

- 警告・提案のみ。変更を禁止しない
- テスト用の `Connection::open_in_memory()` コンテキストは対象外
