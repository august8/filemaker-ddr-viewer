# 0008: 未参照フィールド検出に同テーブル内ベア参照チェックを追加する

- **ステータス**: Accepted
- **日付**: 2026-04-17

## コンテキスト

ADR-0007 で `OccName::FieldName` 形式の参照は検出できるようになったが、FileMaker の計算フィールドでは `FieldName` だけ（ベア参照）で同テーブルのフィールドを参照できる。この形式で参照されているフィールドが「未参照」と誤表示される問題が残っていた。

## 決定

`list_unused_fields_inner` に Step 3 を追加し、`fetch_same_table_field_calcs()` でテーブル別の計算テキストを収集、`has_bare_field_ref()` でベアマッチングを行う。スクリプトステップは対象外とする。

## 理由

FileMaker 仕様として「フィールド計算式内のベア参照は常に同テーブルのフィールドを指す」ため、スコープが確定している。異なるテーブルの同名フィールドへの誤検出が発生しない唯一のケース。スクリプトステップはレイアウトコンテキスト依存で不定なため除外が適切。

## 却下した案

- スクリプトステップのベア参照も対象にする → 実行時コンテキスト依存のため偽陽性が発生しうる。
- ユニーク名のみベア検出する → 実装が複雑になる割に、テーブル内限定の方が FileMaker 仕様に素直。
