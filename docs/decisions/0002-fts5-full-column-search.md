# 0002: FTS5 検索を name + content 全カラム検索にする

- **ステータス**: Accepted
- **日付**: 2026-02

## コンテキスト

初版では `name:"word"*` で要素名のみを検索していた。スクリプトステップ内容・カスタム関数の計算式・テーブルオカレンス名・リレーション述語も検索対象にしたいという要求があった。

## 決定

カラム指定なしの `"word"*` 形式で `name` と `content` を横断検索する。

## 理由

`content` カラムにスクリプトステップ・計算式・TO 名・述語等を格納しており、これらも横断検索できることがツールとして重要。

## 却下した案

`name:"word"* OR content:"word"*` の明示指定 → 記述が冗長でメンテしにくい。
