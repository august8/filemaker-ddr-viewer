# エディタ変更とターミナル実行の同期ルール

AIエージェント（Antigravity、Claude Code 等）は、エディタ上でのファイル変更提案とターミナルコマンドの実行に関して、以下のルールを厳守してください。

## ルールの目的
AIエージェントがファイル変更ツールを使用した直後に、ユーザーがエディタ上で変更を「Accept（承認）」して保存する前にターミナルコマンドが走ってしまうUX上のギャップ（競合状態）を防ぐためです。

## 同期ルール（必須手順）

ファイルを変更（作成・編集）した後に、そのファイルの最新状態に依存するターミナルコマンド（`git commit`, `git push`, ビルドコマンド, テスト実行等）を行う場合、**これらを一度のターンで連続して実行してはなりません。**
必ず以下の手順を踏んでください。

1. **ファイル変更ツールの実行とターンの終了**
   ファイル変更のツール呼び出しを行った後、一度ツール実行を停止（ターンの終了）してください。

2. **ユーザーへの承認要求と待機**
   ユーザーに対して、明確に以下の行動を促してください。
   > 「エディタ上で変更を Accept（承認）し、ファイルを保存してください。完了したら『進めて』などの返信をしてください。」

3. **ユーザーからの合図を待ってからコマンド実行**
   ユーザーから「保存した」「完了」「進めて」などの明確な合図（承認）を得てから、次のターンとしてターミナルコマンド（`run_command` 等）を実行してください。

> [!WARNING]
> 複数ファイルの連続編集自体を禁止するものではありません。「ファイル変更」と「変更結果に依存するコマンド実行」の間を分断することが目的です。
