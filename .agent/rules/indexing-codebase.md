## Indexing Codebase (Context Awareness)

コードベースの構造を正確に把握してから行動すること。

### 禁止事項

- **ファイルパスを推測で記述しない**
  - `list_dir` / `glob` / `grep` 等で実在を確認してからパスを使用すること
- **依存関係を推測で補完しない**
  - import/use の対象モジュールが存在するか確認してから参照すること
- **存在しない関数・型を使用しない**
  - 既存コードで使われているパターンを確認してから新しいコードを書くこと

### プロジェクト構造の重要ポイント

```
src/
  hooks/配下のファイル群     ← 全 invoke() の集約点。ここを先に確認する
  stores/appStore.ts         ← グローバル状態。型変更は全コンポーネントに影響
  types/ddr.ts               ← フロントエンド型定義
src-tauri/src/
  commands/                  ← Tauri IPC コマンド定義
  db/schema.rs               ← SQLite スキーマ（変更は不可逆）
  db/repository/             ← CRUD・検索クエリ（サブモジュール構成）
  parser/                    ← DDR XML パーサー
  analyzer/                  ← 解析エンジン
```

### 作業開始前のチェックリスト

新しいタスクを開始する前に以下を確認すること：

1. `AGENTS.md` の「設計上の重要な判断」を読む
2. 変更対象ファイルが実際に存在するか確認する
3. 関連する既存パターン（同種の実装）を 1 つ以上確認する
4. 変更が「承認が必要な箇所」に該当しないか確認する
