description: コード・PR・設計のレビューを行う
---

指定されたコードまたは変更内容をレビューすること。

## レビュー観点

### 必須チェック

- [ ] `AGENTS.md` の「設計上の重要な判断」に抵触していないか
  - DB ID の扱い（FM ID と DB auto-increment ID の混同）
  - FTS5 検索のカラム指定
  - `invoke()` の集約（`src/hooks/` 配下のファイル以外から呼んでいないか）
- [ ] `unwrap()` が本番コードに含まれていないか（Rust）
- [ ] 新規コードにテストが書かれているか
- [ ] Conventional Commits 形式のコミットメッセージになっているか

### 品質チェック

- [ ] エラーハンドリングが適切か
- [ ] 型安全性（TypeScript `any` の使用・Rust の型定義）
- [ ] 既存パターンとの一貫性

### 🟡 推奨修正
