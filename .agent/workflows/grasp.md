**[SYSTEM INSTRUCTION: READ-ONLY ANALYSIS MODE]**

ファイルを変更せずに、指定されたコード・モジュール・機能の構造を分析すること。

## 分析項目

1. **対象の役割**: このコード・モジュールは何をするか
2. **依存関係（上流）**: 何に依存しているか（import / use / invoke 先）
3. **依存関係（下流）**: 何から参照されているか（どこから呼ばれているか）
4. **Tauri IPC 境界**: フロントエンド ↔ バックエンド間の通信がある場合、コマンド名と型を明示する
5. **変更時の影響範囲**: このコードを変更した場合に影響を受けるファイル・機能
6. **設計上の注意点**: `AGENTS.md` の「設計上の重要な判断」に関連する部分があれば指摘する

## 出力フォーマット

分析結果は箇条書きで簡潔にまとめ、最後に「変更時の影響サマリー」を 2〜3 行で述べること。
