# Plan Skill

コードを**一切編集せず**に、実装計画と原子的なタスクリストを出力すること。

## 出力する成果物

### Implementation Plan

```
## 実装計画

### 概要
### 影響ファイル
### アーキテクチャへの影響
### アプローチ
### リスク・注意点
```

### Task List

- 各タスクは 3 ツールコール以内で完了できる粒度にする
- チェックボックス形式

## 重要

- `AGENTS.md` の「変更時に承認が必要な箇所」に該当する変更を含む場合は必ず明記すること
- 計画を出力したら必ず承認を待つこと。自動的に実装フェーズに移らないこと
